Bakiye ve cari kartındaki Gecikmiş Borç iki okumada AYNI; yaşlandırma / Vade Takip / nakit akışı bugün zaten kartın aldığı kısmı faturadan düşüyor. Örnek: F1 50.000 (vade 10.02), Borç Yaz 30.000; 01.02'de kart 60.000 (S200 = A: önce elle borç 30.000, eksik 30.000 F1'den); 16.02. Küçük program turu gerekir. B (bugünkü — v2.0.23'ten beri): fatura kendi açığıyla — Açık Faturalar'da F1 50.000 ve gecikmiş; aynı 30.000 kartın taksitlerinde de görünür (aynı para iki raporda iki kez açık); kart faturanın tamamını aldıysa fatura 50.000 gecikmiş, cari kartında gecikmiş 0. Kâhin bu kararla güncellenir. Yaygın programlarda: doğrulanmış kaynak okunmadı. ## 2. API SÖZLEŞMESİ (alan anlamları; beklenen değer DEĞİL — bağdaştırıcının okuması için)
Fatura ayrıntısı ve fatura listesi yanıtında: `open` = GÖSTERİLEN açık (S229 / S230 = A; kartın aldığı kısım düşülmüş); `ownOpen` = faturanın KENDİ açığı (kapama kuralıyla; eskiden `open`'ın taşıdığı anlam); `inPlan` = kart(lar)ın faturadan aldığı kısım; kartın tamamını aldığı faturanın ödeme durumu `installment` ('Taksitte'). Eski program sürümlerinde `ownOpen` alanı YOKTUR — orada `open` kendi açıktır.
