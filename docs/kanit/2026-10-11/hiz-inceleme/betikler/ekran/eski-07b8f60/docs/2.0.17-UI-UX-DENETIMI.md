# 2.0.17 — Uzman UI / UX denetimi ve stres testi (02.10.2026)

Kullanıcı isteği: "uzman UI ve uzman UX olarak tüm kartların, pillerin tasarımının uygun olduğunu ve kod kısmının uçtan uca doğru
çalıştığını test et; baş mimar / baş mühendis şapkasıyla gerçek stres testi". Bu belge yöntemi, bulguları ve yapılan düzeltmeleri
yazar. Bulgular tablosu her koşuda yeniden üretilir: `node test/e2e/ui-ux-217.mjs` → `test/e2e/artifacts/ui-ux-217/bulgular.md`
(ekran görüntüleri aynı klasörde).

## Yöntem
1. **Ekran ekran gezinti (Playwright, 1440×900 ve 1024×700):** gerçek veriyle (Excel'den 40 kayıtlı sayfa, tedarikçi + müşteri,
   alış faturası, taksitli satış, satıştan iade, alınan çek, verilen senet, görev) 46 ekran açıldı: ana ekran, şirket seçici,
   + Sayfa menüsü, zil, Tahsilat Takvimi pil kartı, detay kartı, Görevler, Mesajlar, Cari (liste / kart / tahsilat formu / yeni cari),
   Kasa (nakit / Tahsilat Ekle / banka transferi), Stok (liste / kart / yeni ürün), Fatura (liste / kart / yeni fatura), Çek / Senet
   (liste / kart / ciro formu), Taksitler (liste / kart), Raporlar (Vade Takip, Rapor Merkezi, Banka ve POS Hareketleri, Cari Ekstre,
   Stok Durumu), Personel Raporu, ANLIK DURUM → Rapor Al, Ayarlar, Boş Sayfa formu, Yönetim'in 7 sekmesi, dar ekranda ana ekran /
   fatura formu / cari kartı.
2. **Her ekranda 7 otomatik denetim:** tarayıcı hatası yok · yatay taşma yok · pencere ekrana sığıyor · kırpılan yazı yok · tıklama
   hedefi ≥ 22 px · pasif düğmenin nedeni var (title ya da kartta yazı) · küçük yazı kontrastı ≥ 3:1 (WCAG AA büyük yazı / arayüz
   eşiği; ikincil yazılar 4,5:1 hedefiyle düzeltildi). Ayrıca "şeritler yer kavgası yapmıyor" denetimi (3 sn'de DOM değişimi ≤ 4,
   takvim şeridi aynı düğüm).
3. **Uzman gözüyle inceleme:** ekran görüntüleri tek tek bakıldı (kart / pil hiyerarşisi, yazım düzeni, boş durum metinleri, düğme
   adları, renk anlamı).
4. **Stres:** `npm run test:mutabakat -- --islem 5000 --tohum 3 --tohumlar 2 --her 1` (iki tohum × 5.000 rastgele işlem; her
   işlemden sonra bağımsız modelle ve mutabakat kapısıyla kuruşu kuruşuna karşılaştırma) + `npm run test:e2e` + bütün senaryolar.
