## 1. Plandan türetilen kurallar (uygulama kararları; plan susan yerde yaygın uygulama)

| # | Kural | Kaynak |
|---|---|---|
| K1 | "Şüpheli Alacağa Al": B 128 / A 120, tutar en çok carinin borç bakiyesi − zaten şüphelide olan tutar; neden (Karşılıksız Çek / Protestolu Senet / Dava / İcra / Diğer). Cari kartı bakiyesi DEĞİŞMEZ; 120 o tutar kadar azalır, 128 artar. | §3.11b/2 |
| K2 | Yalnız müşteri (120) carisi; tedarikçi/diğer cari 409 (plan "B 128 / A 120"). | §3.11b/2 |
| K3 | Carinin alacak satırı (tahsilat, alınan evrak, Alacak Yaz, iade faturası, taksit tahsilatı, kapatılan kartın vazgeçilen kalanı) kayıt tarihinden sonra geldiyse ÖNCE şüpheli tutardan düşer: A 120 yerine A 128 (o tutar kadar; aşan kısım A 120). Birden çok şüpheli kayıtta önce en eskisi. Aynı gün sırası: al → karşılık → alacak satırı → çıkar (aynı günde alınan kayda o günün tahsilatı düşer; çıkarma günün sonunda). Plan "tahsilat" der; her alacak satırı için aynı kural seçildi — aksi hâlde carinin 120 bakiyesi eksiye düşerdi (çekle ödenen şüpheli alacak 120'de −, 128'de + görünürdü). Tahsil edilen/kalan SAKLANMAZ, her seferinde bu kuralla türetilir (tahsilatın silinmesi/düzeltilmesi/geri yüklenmesi kendiliğinden tutarlı). | §3.11b/2 (genişletme) |
| K4 | "Şüpheliden Çıkar": kapanış gününde KALAN şüpheli tutar B 120 / A 128; o kayda ayrılmış karşılık varsa B 129 / A 644 (konusu kalmadı). Kalan 0 ise (tamamı tahsil edilmiş) çıkarılacak şey yok → 409. | §3.11b/2–3 |
| K5 | "Karşılık Ayır": B 654 / A 129, kayıt başına toplam karşılık ≤ o kaydın kalan şüpheli tutarı (fazlası 400). | §3.11b/3, VUK 323 |
| K6 | 644 kuralı: şüpheli alacak kısmen/tamamen tahsil edilince ayrılan karşılık KALAN şüpheli tutarı aşıyorsa aşan kısım aynı gün B 129 / A 644 (karşılık ≤ kalan değişmezi). Plan: "tahsil edilirse ayrılan karşılık kadar B 129 / A 644". | §3.11b/3 |
| K7 | "Değersiz Alacak Yaz": tutar ≤ kalan şüpheli; karşılık varsa önce B 129 (karşılık kadar), kalanı B 659; A 128. Cari kartına "Değersiz Alacak" ALACAK satırı yazılır (source `doubtful`): cari bakiyesi o tutar kadar kapanır. Satır cari kartından silinmez/düzeltilmez (409). | §3.11b/3 |
| K8 | Dönem kilidi (409 period-locked), ileri tarih (400 date-future), istek kimliği (aynı kimlik aynı gövde → yeniden yazılmaz; farklı gövde 409 request-id-reused), yetki (Cari Yönetimi + Şüpheli Alacak İşlemleri: admin ve muhasebe; personel/avukat 403), audit (`doubtful.*`), Silinenler (kayıt/karşılık/değersiz silinince ters kayıt = defterden düşer; Silinenler'den geri yüklenince aynı tarih ve tutarla döner), Şirket Verisini Sıfırla (hareketlerle silinir). | §3.11b/4 |
| K9 | Mutabakat Testi: 128 = Σ etkin şüpheli kayıtları − (tahsil edilen + değersiz yazılan + şüpheliden çıkarılan); 129 = −(Σ karşılık − çözülen); cari bazında 120 + 128 = cari kartı bakiyesi; her şüpheli başlığının kaydı, her kaydın başlığı var (`doubtful:records`). | §3.11b/4 |
| K10 | Hiçbir Banka Fişi rolünde 128/129 (ve 644/654) seçilemez (FORBIDDEN_GL; 400 bank-gl-forbidden). | §3.11b/6 |

| K12 | Kilit izi: şüpheli kayıtları/karşılıklar `since: "2.3.0"` girdileriyle; 2.2.0'ın kaydettiği izle karşılaştırma `lockDigestOf(store, kilit, { version: "2.2.0" })` ile aynı kalır. Durum (open → released) ize girmez (kilitli ayda alınan kayıt açık ayda çıkarılır); iptal (cancelled) bayrağı girer. | §3.11a kalıbı |

## 2. Kabul sayıları (plandan; kuruş)

Sahte saat 08.10.2026. Cari "ABC Ltd." müşteri. Başlangıç: Borç Yaz 10.000 (B 120 / A 602). Hesaplar: 100 Kasa, 120, 128, 129, 644, 654, 659.

| Adım | İşlem | Yevmiye | 120 | 128 | 129 | 644 | 654 | 659 | Cari bakiyesi | Kasa 100 |
|---|---|---|---|---|---|---|---|---|---|---|
| 0 | Borç Yaz 10.000 (01.10) | B 120 / A 602 10.000 | 10.000 | 0 | 0 | 0 | 0 | 0 | 10.000 | 0 |
| 1 | Şüpheli Alacağa Al 4.000 (05.10, Dava) | B 128 / A 120 4.000 | 6.000 | 4.000 | 0 | 0 | 0 | 0 | 10.000 | 0 |
| 2 | Karşılık Ayır 2.500 (06.10) | B 654 / A 129 2.500 | 6.000 | 4.000 | −2.500 | 0 | 2.500 | 0 | 10.000 | 0 |
| 3 | Tahsilat 3.000 nakit (07.10) | B 100 / A 128 3.000 · 644 kuralı: B 129 / A 644 1.500 | 6.000 | 1.000 | −1.000 | −1.500 | 2.500 | 0 | 7.000 | 3.000 |
| 4 | Değersiz Alacak Yaz 1.000 (08.10) | B 129 1.000 / A 128 1.000 (karşılıklı; 659'a 0) | 6.000 | 0 | 0 | −1.500 | 2.500 | 0 | 6.000 | 3.000 |

Mizan denge denetimi (adım 4): 100 (3.000) + 120 (6.000) + 128 (0) + 129 (0) + 644 (−1.500) + 654 (2.500) + 602 (−10.000) = 0 ✓.
Cari bazında: 120 + 128 = 6.000 = cari kartı bakiyesi ✓ (adım 1–3'te 6.000 + 4.000 = 10.000, 6.000 + 1.000 = 7.000).

## 3. "Nasıl Bozarım" listesi (testler bu listeden çıkar)

1. Sıra değiştir: karşılık → al (409 kayıt yok); tahsilat → al (tahsilat önce geldiyse şüpheliden düşmez: K3 "kayıt tarihinden sonra"); değersiz → çıkar; iki kaydın tarih sırası ters girilirse (al 04.10, sonra al 03.10) tahsilat önce 03.10'a.
2. Aynı adlı iki cari (P).
3. Kilitli dönem (I); kilit konduktan sonra kilitli kaydı çıkar/sil/karşılık.
4. İleri tarih, geçersiz tarih, boş tarih (J); kayıt tarihinden ÖNCE tarihli karşılık/çıkarma/değersiz → 400 date-before-record.
5. İki kez aynı istek kimliği (K); aynı anda iki istek (O).
6. Sil + geri al (L); karşılığı silip geri al; değersizi silip geri al; çıkarılmış kaydı sil (başlıkları iptal) ve geri al.
7. Sıfırla (M).
8. Eski sürüm verisi (N).
9. Tutar > borç bakiyesi (F); 0 / eksi / 3 ondalık tutar → 400 amount-range.
10. Karşılık > şüpheli (G).
11. Tahsilat şüpheliyi aşınca (D); çekle tahsilat (K3) → B 101 / A 128; iade faturası → A 128.
12. Değersiz yazınca cari kapanışı (K7; adım 4); karşılıksız değersiz (B).
13. Karşılıksız evrak kısayolu (H); portföydeki (karşılıksız olmayan) evrakla kısayol → 409.
14. Tedarikçi carisi (W); silinmiş cari (404); yetkisiz (Q).
15. Ham SQL bozması (T): kayıt tutarı, başlık iptali, kaydı olmayan başlık.
16. Kapı eşdeğerliği (gateVerify): şüpheli carisine tahsilat/çek/iade yazımında dokunulan varlıklar yolu ile tam kapı aynı karar.
17. Değersiz satırı cari kartından sil/düzelt → 409; Alacak Yaz ile cari eksiye → şüpheli önce düşer (128 ≥ 0 kalır).
18. Şüpheliden Çıkar'dan sonra tahsilat → A 120 (şüpheli kalmadı); çıkarılmış kayda yeniden al → yeni kayıt (eski kalır).
